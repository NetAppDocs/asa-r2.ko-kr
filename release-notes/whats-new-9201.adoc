== SAN 데이터 마이그레이션

[[security]]
== 보안

[cols="2,4"]
|===
| 업데이트 | 설명 


| link:../learn-more/additional-supported-ontap-features.html#fc-sp-3-authentication-and-encryption["Broadcom 보안 HBA를 사용한 FC-SP-3 인증 및 암호화 지원"] | ONTAP은 ASA r2 시스템과 함께 Broadcom 보안 HBA에서 Fibre Channel 보안 프로토콜 3(FC-SP-3) 인증 및 암호화를 지원합니다. FC-SP-3 지원을 통해 하드웨어 수준의 종단 간 암호화 및 장치 인증을 활성화하여, T11 Fibre Channel 보안 표준을 준수하면서 FC 및 NVMe/FC SAN 호스트와 ONTAP 스토리지 시스템 간에 전송되는 데이터를 보호할 수 있습니다. 


| 웹 관리 가용성 보호 및 사전 클러스터링 기능 향상 지원 | 연결 폭주 중에 웹[1] 관리 API 가용성을 유지하는 개선 사항이 구현되었습니다. 또한 노드 관리 LIF가 클러스터 설정을 기다리는 동안 DHCP 연결을 유지하고 갱신할 수 있도록 Precluster 동적 호스트 구성 프로토콜(DHCP) 처리가 향상되었습니다. 


| link:../learn-more/additional-supported-ontap-features.html#external-key-management-for-encryption-at-rest["스토리지 VM 볼륨 암호화 키의 자동 마이그레이션 지원"] | 데이터 스토리지 VM에서 외부 키 관리자를 활성화하면 ONTAP은 해당 스토리지 VM의 볼륨 암호화 키를 관리자 범위 키 관리자에서 새 데이터 스토리지 VM 키 관리자로 자동으로 마이그레이션합니다. 이를 통해 외부 키 관리로의 전환이 간소화되고 표준 워크플로에서 별도의 수동 마이그레이션 단계를 제거할 수 있습니다. 


| link:../learn-more/additional-supported-ontap-features.html#multi-admin-verification-mav["MAV 그룹 지원"] | MAV 승인 그룹에는 개별 관리자 외에도 ID 공급자(IdP), Active Directory(AD) 및 LDAP(nsswitch) 그룹을 승인자로 포함할 수 있습니다. 지원되는 그룹 유형에는 Entra ID, ADFS, AD 도메인 그룹 및 LDAP 그룹이 있습니다. IdP, AD 또는 LDAP 디렉터리에서 사용자를 추가하거나 제거해도 MAV 구성을 변경할 필요가 없습니다. 


| link:../learn-more/additional-supported-ontap-features.html#snmp["SNMP의 SHA-512 지원"] | ONTAP은 SNMPv3 사용자에 대해 SHA-512 인증을 지원합니다. 이 개선 사항을 통해 SHA-512 인증이 필요한 스위치를 포함하여 외부 SNMP 클라이언트 및 스위치 모니터링에 더욱 강력한 SNMPv3 인증을 사용할 수 있습니다. 
|===


[[storage-efficiency]]
== 스토리지 효율성

[cols="2,4"]
|===
| 업데이트 | 설명 


| link:../learn-more/additional-supported-ontap-features.html#data-reduction-rate-drr["스토리지 효율성 데이터 감소율에 대한 간소화된 보고 지원"] | 스토리지 효율성 데이터 감소율(DRR)은 감소 가능한 데이터만 포함하여 ONTAP 스토리지 효율성 공간 절약에 대한 보다 정확한 평가를 제공합니다. ONTAP 9.19.1 및 이전 버전에서는 DRR에 감소 가능한 데이터와 감소 불가능한 데이터가 모두 포함됩니다. 


| SAN 복사 오프로드 성능 향상 지원 | ONTAP은 해당하는 NVMe 및 SCSI 복사 워크로드에 대해 SAN 복사 오프로드 성능을 향상시킵니다. 자세한 내용은 NetApp 담당자에게 문의하십시오. 


| 자동 중복 제거 스케줄러(ADS) 최적화 | 자동 중복 제거 스케줄러(ADS)가 개선되어 노드당 더 많은 동시 중복 제거 세션을 허용하고, 클라이언트 I/O 균형을 더 잘 맞추기 위해 더욱 스마트하고 타겟팅된 스로틀링을 제공합니다. DP 볼륨(SnapMirror 전송) 및 글로벌 중복 제거 세션에 대한 중복 제거 작업은 일반 볼륨 중복 제거와 함께 더욱 최적으로 관리되어 경합 및 메타데이터 증가를 줄입니다. 특히 혼합 워크로드 환경에서 구성 변경 없이 스토리지 효율성을 향상시킬 수 있습니다. 이 기능은 기본적으로 활성화되어 있습니다. 
|===
