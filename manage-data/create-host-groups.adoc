= ASA r2 시스템에서 호스트 그룹을 만듭니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ASA r2 시스템에서 _호스트 그룹_은 호스트가 스토리지 유닛에 액세스할 수 있도록 하는 메커니즘입니다. 호스트 그룹은 SCSI 호스트의 경우 igroup을, NVMe 호스트의 경우 NVMe 서브시스템을 의미합니다. 호스트는 자신이 속한 호스트 그룹에 매핑된 스토리지 유닛만 볼 수 있습니다. 호스트 그룹이 스토리지 유닛에 매핑되면 해당 그룹의 구성원인 호스트는 스토리지 유닛을 마운트(디렉터리 및 파일 구조 생성)할 수 있습니다.

호스트 그룹은 스토리지 유닛을 생성할 때 자동으로 또는 수동으로 생성됩니다. 스토리지 유닛 생성 전이나 후에 다음 단계를 따라 호스트 그룹을 생성할 수도 있습니다.

.단계
. System Manager에서 * Host * 를 선택합니다.
. 호스트 그룹에 추가할 호스트를 선택합니다.
+
첫 번째 호스트를 선택하면 호스트 그룹에 추가하는 옵션이 호스트 목록 위에 나타납니다.

. 호스트 그룹에 추가 * 를 선택합니다.
. 호스트를 추가할 호스트 그룹을 검색하여 선택합니다.


.다음 단계
