= ASA R2 스토리지 시스템에 대한 지원 사례를 제출하고 확인합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
도움이 필요한 문제가 발생하면 ONTAP System Manager를 사용하여 기술 지원에 케이스를 제출하거나 완료된 케이스 또는 진행 중인 케이스를 확인할 수 있습니다.

link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["Active IQ에 등록되었습니다"^] ASA r2 시스템에 대한 지원 사례를 보려면 권한이 있어야 합니다.

.단계
. 지원 사례를 제출하려면 시스템 관리자에서 *클러스터 > 지원*을 선택한 다음 *NetApp 지원으로 이동*을 선택하십시오.
. 이전에 제출한 사례를 보려면 System Manager에서 *클러스터 > 지원*을 선택한 다음 *내 사례 보기*를 선택하십시오.
