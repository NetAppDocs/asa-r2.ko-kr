= ASA R2 스토리지 시스템에서 호스트 접속을 확인합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
호스트 데이터 작업에 문제가 있는 경우 ONTAP System Manager를 사용하여 호스트에서 ASA R2 스토리지 시스템으로의 접속이 활성 상태인지 확인할 수 있습니다.

.단계
. System Manager에서 * Host * 를 선택합니다.
+
System Manager는 호스트 그룹 이름 옆에 호스트 연결 상태를 표시합니다:

+
** *OK*: 모든 이니시에이터가 두 노드 모두에 연결되었음을 나타냅니다.
** *부분적으로 연결됨*: 일부 이니시에이터가 두 노드 모두에 연결되지 않았음을 나타냅니다.
** *None Connected*: 연결된 이니시에이터가 없음을 나타냅니다.




.다음 단계
연결 문제를 해결하려면 호스트를 업데이트하십시오. ONTAP은 15분마다 연결 상태를 다시 확인합니다.
